確率変数 $X$ の基礎定義

確率変数 $X$ のとりうる値 $x_i$ と、その確率 $p_i$ の対応関係を確率分布といいます（ただし $p_i \geqq 0,\; \sum p_i = 1$）。

Expected Value

期待値（平均） $E[X]$

値 × 確率 の総和（分布の重心）

$$E[X] = \sum_{i=1}^{n} x_i p_i = m$$
Variance

分散 $V[X]$

偏差 $(X - E[X])$ の2乗の期待値 ＝ 「2乗の平均 － 平均の2乗」

$$V[X] = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$
Standard Deviation

標準偏差 $\sigma[X]$

分散にルートをかぶせて元の単位に戻したもの

$$\sigma[X] = \sqrt{V[X]}$$
超重要公式

確率変数の変換 $Y = aX + b$

元の確率変数 $X$ を $a$ 倍して $b$ 足した新しい変数 $Y = aX + b$ の期待値・分散・標準偏差はどう変化するか？（後の「標準化」や「標本比率」の導出で大活躍します）

① 期待値は「$a$ 倍して $b$ 足す」そのまま！
$$E[Y] = E[aX + b] = aE[X] + b$$
② 分散は「平行移動 $+b$ は無関係、倍率は $a^2$ 倍」！
$$V[Y] = V[aX + b] = a^2 V[X]$$
③ 標準偏差は「$|a|$ 倍」（絶対値を忘れずに）
$$\sigma[Y] = \sigma[aX + b] = |a|\sigma[X]$$
直感イメージ： 全員のテストの点数を $+10$ 点（$+b$）底上げしても、平均点は $10$ 点上がるだけで「散らばり具合（分散・標準偏差）」は全く変わりません！

離散型の確率変数 と 連続型の確率変数

離散型（とびとびの値） 例：サイコロの目、コインの表の回数

代表選手：二項分布 $B(n, p)$

1回の試行で事象 $A$ の起こる確率が $p$ のとき、この試行を独立に $n$ 回繰り返す（反復試行）中で事象 $A$ が起こる回数 $X$ の分布。

期待値 $E[X] = np$
分散 $V[X] = np(1-p)$
標準偏差 $\sigma[X] = \sqrt{np(1-p)}$

※ $P(a \leqq X \leqq b)$ は、棒グラフ（相対度数）の縦棒の和で求める。

連続型（なめらかな値） 例：身長、体重、測定誤差

確率密度関数 $f(x)$ と面積＝確率

連続的な値をとる確率変数 $X$（範囲 $\alpha \leqq X \leqq \beta$）では、曲線 $y = f(x)$ と横軸で囲まれた「面積（定積分）」が確率になります。

(i) 常に $f(x) \geqq 0$
(ii) 区間 $a \leqq X \leqq b$ の確率： $P(a \leqq X \leqq b) = \displaystyle\int_{a}^{b} f(x)\,dx$
(iii) 全区間の面積は $1$： $P(\alpha \leqq X \leqq \beta) = \displaystyle\int_{\alpha}^{\beta} f(x)\,dx = 1$
※ ピンポイント1点の確率は面積ゼロなので $P(X = k) = 0$

① 標本平均 $\overline{X}$ の分布

母平均 $m$、母標準偏差 $\sigma$ の母集団から大きさ $n$ の無作為標本 $X_1, X_2, \dots, X_n$ を抽出したとき、それらの平均 $$\overline{X} = \frac{X_1 + X_2 + \cdots + X_n}{n}$$ 自身もまた、標本を取り直すたびに値が少しずつブレる確率変数になります。

標本平均の期待値 $E[\overline{X}]$
中心の位置は母平均 $m$ と一致！
$$E[\overline{X}] = m$$
標本平均の標準偏差 $\sigma[\overline{X}]$
$n$ 個平均するとブレ幅は $\dfrac{1}{\sqrt{n}}$ に縮小！
$$\sigma[\overline{X}] = \frac{\sigma}{\sqrt{n}}$$
💡 なぜ分母に $\sqrt{n}$ がつくのか？（導出）
$$V[\overline{X}] = V\left[\frac{X_1 + \cdots + X_n}{n}\right] = \frac{1}{n^2}\left(V[X_1] + \cdots + V[X_n]\right) = \frac{1}{n^2}\cdot n\sigma^2 = \frac{\sigma^2}{n}$$ これのルートをとるので $\sigma[\overline{X}] = \sqrt{\dfrac{\sigma^2}{n}} = \dfrac{\sigma}{\sqrt{n}}$ となります。

② 母比率 $p$ と 標本比率 $R$ の分布

ある特性をもつ要素の母比率が $p$ である母集団から大きさ $n$ の標本を抽出し、その特性をもつ個数を $X$ とすると、標本比率は $R = \dfrac{X}{n}$ と表せます。

【ノート Page 6 の導出ステップ】
1. 個数 $X$ は二項分布 $B(n, p)$ に従うので、$E[X]=np,\; V[X]=np(1-p)$。
2. $R = \dfrac{1}{n}X$ に一次変換の公式を適用すると：
$$E[R] = E\left[\frac{X}{n}\right] = \frac{1}{n}E[X] = \frac{1}{n}\cdot np = p$$ $$V[R] = V\left[\frac{X}{n}\right] = \frac{1}{n^2}V[X] = \frac{np(1-p)}{n^2} = \frac{p(1-p)}{n}$$ $$\sigma[R] = \sqrt{V[R]} = \sqrt{\frac{p(1-p)}{n}}$$
$n$ が十分に大きいとき、標本比率 $R$ が従う分布：
$$R \sim N\left(p,\; \frac{p(1-p)}{n}\right)$$

なぜ母標準偏差 $\sigma$ の代わりに「標本の標準偏差 $s$」を代入してよいのか？

生徒が抱くもっともな疑問

「母平均 $m$ が分からない（未知だ）から推定しているのに、なぜ公式 $\overline{X} \pm 1.96\dfrac{\sigma}{\sqrt{n}}$ の中にある母標準偏差 $\sigma$ は『知っている前提』なの？ 母集団全体が分からないなら $\sigma$ も分からないはずでは？」

実際の入試や模試でも、「母標準偏差は与えず、抽出した $n=100$ 個のデータの標本標準偏差 $s$ が与えられている」問題が頻出します。

1 理由：$n$ が十分に大きいとき、$s$ は $\sigma$ に限りなく近づくから（一致性）

大数の法則により、標本の大きさ $n$ が十分に大きいとき（目安として $n \geqq 30\sim 100$）、手元の標本から計算した標準偏差 $s$ は真の母標準偏差 $\sigma$ とほぼ同じ値（$s \approx \sigma$）になります。そのため高校数学Bの枠組みでは、公式の $\sigma$ の位置にそのまま $s$ を代入してよいことになっています。（※ $n$ が小さい場合は大学で学ぶ「$t$ 分布」を使います）

2 母比率の推定と「まったく同じ発想」でつなげて理解しよう！

母比率 $p$ の区間推定（ノート1・7枚目）
未知の母比率 $p$ を、標本比率 $R$ で代用：
$$\sqrt{\frac{p(1-p)}{n}} \;\longrightarrow\; \sqrt{\frac{\boldsymbol{R}(1-\boldsymbol{R})}{n}}$$
母平均 $m$ の区間推定
未知の母標準偏差 $\sigma$ を、標本標準偏差 $s$ で代用：
$$\frac{\sigma}{\sqrt{n}} \;\longrightarrow\; \frac{\boldsymbol{s}}{\sqrt{n}}$$

仮説検定は計算よりも「日常語の感覚」と「統計学の厳密な言い回し」のギャップで混乱します。授業の解説やテスト対策でそのまま使える5つの重要ロジックです。

1

なぜ「$H_0$ を採択する」と言わず「棄却しない（保留）」と言うのか？

× 日常語の誤解： 「疑いが晴れた（棄却されなかった）なら、帰無仮説 $H_0$ が正しいと証明されたってことだよね？」
◎ 統計学の論理（裁判の推定無罪モデル）：
裁判で「有罪の決定的な証拠が見つからず無罪（処分保留）になった」からといって、「被告人が100%潔白であると証明された」わけではありません。
同様に、棄却域に入らなかったのは「$H_0$ が間違っていると断定するだけの証拠が足りなかった（証拠不十分で保留）」にすぎません。
2

「帰無仮説（$H_0$）」という難しい漢語の正体と「背理法」

言葉の由来： 「無（効果なし・差がない・ただの偶然）に帰（き）する仮説」、あるいは「後で叩き潰して無に帰すために、あえて立てる当て馬の仮説」です。

数学Aの「背理法」との比較：
・数学Aの背理法： 命題の否定を仮定し、「論理的な矛盾（起きる確率 $0\%$）」を導いてひっくり返す。
・統計の仮説検定： 主張の否定（$H_0$）を仮定し、「現実的にめったに起きない極小確率（$5\%$ 未満）」を導いてひっくり返す（＝確率的背理法）。
3

「有意水準 $5\%$」や「有意な差」の『有意』とはどういう意味？

× 日常語の誤解： 「5%ぶん意味がある」「5%の効果がある」「すごく大きな差がある」
◎ 統計学の本来意味：
英語の statistically significant の訳語で、「ただの偶然の誤差（ブレ）として片付けるには無理がある（意味のある差だ）」という意味です。
差の「大きさ」ではなく、「偶然という言い訳が通用しない確からしさ」を表しています。
4

P値（P-value）の「主語の入れ替わり」に要注意！

例えば計算の結果 $P = 0.03\;(3\%)$ となったとき、これを「帰無仮説 $H_0$ が正しい確率が $3\%$ だ」と解釈するのは誤りです。

$$\text{誤： } P(H_0\text{が真} \mid \text{データ}) \quad \neq \quad \text{正： } P(\text{今回以上に極端なデータ} \mid H_0\text{が真})$$

あくまで「もし $H_0$ が100%正しい世界線だとしたら、今回のデータがどれくらいレアキャラか」を計算しているだけです。

5
